# ReactComponent — DK2 Input demo

A minimal React + TypeScript playground to prototype the DK2 Input component (floating label, descriptions, states for default/error/disabled/read).

## Scripts

- `npm install` — install dependencies
- `npm run dev` — start Vite dev server
- `npm run build` — production build
- `npm run preview` — preview the production build

> Примечание: в некоторых CI/песочницах внешние npm-запросы могут блокироваться. Если установка зависимостей падает с 403, повторите попытку в среде с доступом к registry.npmjs.org.
